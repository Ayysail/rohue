# 🎨 RoHue

### **Your Roblox. Your Hue.**

RoHue is a **free and open-source Chrome extension** that lets you customize the appearance of the Roblox website.

Change the colors and appearance of your Roblox experience — including the **sidebar, topbar, navigation, search bar, and more**.

**No subscriptions. No premium plan. $0 forever.**

# 🚀 Installation

RoHue is currently installed manually through **Chrome Developer Mode**.

Don't worry — it's easier than it sounds!

### 1️⃣ Download RoHue

Download the latest version from the **Releases** page.

### 2️⃣ Extract the files

If the download is a ZIP file, extract it somewhere you can keep the extension folder.

### 3️⃣ Open Chrome Extensions

Open:

`chrome://extensions/`

### 4️⃣ Enable Developer Mode

Turn on **Developer mode** in the top-right corner.

### 5️⃣ Click "Load unpacked"

Click **Load unpacked**.

### 6️⃣ Select the RoHue folder

Select the extracted RoHue extension folder.

### 🎉 Done!

Open Roblox and start customizing your experience.
