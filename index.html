Easy to install. Seriously.

RoHue is installed locally through Chrome Developer Mode. Don't worry — it only takes a few steps.

1
Download RoHue Download the latest release from GitHub.
2
Open Chrome Extensions Go to chrome://extensions/
3
Enable Developer Mode Turn on Developer Mode in the Extensions page.
4
Load Unpacked Unzip the RoHue download and select its folder using Load Unpacked.
5
Customize Roblox! Open Roblox and start making the website look like yours.
